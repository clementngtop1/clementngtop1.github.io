# Vince Tech AI Platform Demo

Staywhale pilot demonstration for the Vince Tech AI Platform.

## Open the demonstration

- [Client walkthrough](https://clementngtop1.github.io/staywhale-login.html)
- [Staywhale dashboard and assistant](https://clementngtop1.github.io/staywhale.html)
- [Platform control center](https://clementngtop1.github.io/)

The demonstration uses fictional business records. It supports sample queries, reporting, CSV export, print/PDF and browser-local routine configuration. No real account credentials are required. Live model calls, external data connections, production authentication and unattended scheduling are not enabled.

## Hosting

This repository contains the public static web files. GitHub Pages publishes the root of the main branch. Updates pushed here are published automatically.
